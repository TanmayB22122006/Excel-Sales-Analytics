# 📊 Advanced Excel Sales Analytics & Data Diagnostics

## 🚀 Project Overview
This project is a comprehensive Excel-based data analysis and diagnostics assessment. It demonstrates end-to-end data processing, from raw data cleaning and anomaly detection to advanced reporting using complex formulas and dynamic Pivot Tables.

## 🛠️ Key Skills & Functions Demonstrated
* **Data Integrity & Diagnostics:** Identified duplicate records, trailing whitespaces, case inconsistencies, and broken foreign keys.
* **Advanced Formulas:** Heavily utilized `INDEX/MATCH`, `VLOOKUP`, `SUMIFS`, `MAXIFS`, `COUNTIFS`, `SUMPRODUCT`, and Array functionalities (`TEXTJOIN` + `LARGE`).
* **Dynamic Reporting:** Built automated Pivot Tables with calculated fields, percentage of row totals, and date grouping (Quarters).
* **Data Cleaning:** Standardized data using `TRIM`, `PROPER`, and custom fraction-based deduplication logic (`1/COUNTIF`).

## 📁 Project Structure

### Phase 1: Data Cleaning & Quality Diagnostics 🧹
* Counted exact unique duplicate entries without double-counting.
* Handled leading/trailing whitespaces in string data.
* Standardized case-sensitive text (e.g., "mumbai" vs "MUMBAI") to find distinct counts.
* Diagnosed relational issues (missing foreign keys) between Sales and Customer data.
* Detected promotional abuse anomalies using multi-condition `COUNTIFS`.

### Phase 2: Pivot Table Analysis 📈
* Created cross-tabulations for Revenue distribution across regions and categories.
* Formatted dynamic metrics like `% of Row Total` and `Average Profit Margin`.
* Implemented Custom Calculated Fields directly within Pivot architectures.

### Phase 3: Advanced Business Logic 💡
* Generated dynamic top-N rankings without manual sorting.
* Calculated cumulative time-series data using date logic (`<= DATE()`).
* Extracted the 2nd highest selling product using combination logic.
* Concatenated Top 5 Sales Reps into a single string using pipe (`|`) delimiters.
